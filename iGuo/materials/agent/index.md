# 智能体

**新方法论**：要让它具备智能化能力、介入一个智能体的时候，一开始先串一个 PI 进去。PI 足够轻，也足够好用，只要本地装过 PI 就可以用；这个限制会让一部分人不好走，但它可以先让流程跑起来。

**性质**：比较临时的策略，适合在命令行做临时接入，拓展能力比较强。它来自 hermes 的工程思路——直接借用一些外部工具，写代码也好，干别的也好。

**记忆库导出**：想把智能体的记忆库拿出来看看是个什么情况，觉得有必要导出。打算用自己的工具链做这件事，让它设计一个导出流程，照着流程就能看清状况。这是智能体本身的事。

**常识工作能力**：充分利用 AI 越来越强的常识工作能力，让它掌握琐碎的工作流程，特别是每个环节，构建可持续迭代的循环，不断用新流程增强质量。

**中间看不懂**：主要困难在于 AI 执行过程中有大量中间看不懂的东西。

**天然门槛**：从技术上没有好办法，因为 AI 有 AI 的思考方式，与人之间存在天然门槛。

**术语与决策**：措辞严格使用既有术语，不用口语。决策思路写在开发者文档里，按「背景 / 选项 / 影响 / 建议」梳理清楚；不用「要你拍板」这类说法把决策推给用户。
