# 沟通

**邮箱申请**：因为没有姓名，邮箱申请没法处理；中间断了一次，需要持续跟踪。这是沟通上要注意的一点。

**录企业宣传片**：可以做视频把工具改变流程的过程录下来，得到不错的企业宣传片；哪怕是本地版本，也能看到工具已经在改变我们的流程。

**人机沟通概念体系**：下一个最难的事情是怎么进行「人机沟通」这个概念的体系；它本身可以作为知识工作任务来做，但还没想好工作流怎么设计；人的可理解性是其中的关键点。

**先接飞书**：沟通云的工程思路是先接飞书，先把「消息到备忘」这个机制做出来，直接写飞书文档；不必等平台上线才做这件事。

**飞书 + GH**：只要接了飞书命令行工具和 GH，大部分团队沟通的事情都能搞定。
