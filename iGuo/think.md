# 认知工程

## 拒绝与权力

**困惑**：为什么“拒绝”和“权力”密切相关？

**解释链**：拒绝也是一种选择，拒绝了什么，往往意味着主动放弃了什么。
拒绝能力可以体现真实权力，内部如此，外部市场也一样。

**案例**：我们拒绝招聘而要求课堂——承担招不到人的风险，且自己能培养。
恰恰因为两点都做到：有足够多的候选人（供给冗余），又自己可以培养（自给能力）。

**机制**：两个条件缺一不可。
- 只有供给冗余而无自给能力 → 拒绝只是挑选（议价能力）
- 两者都有 → 拒绝是定义自己是谁（我们只要经过课堂培养的人）
- 权力不是拒绝本身，而是拒绝之后仍能闭环。

**推论**：拒绝是昂贵的信号 → 拒绝可以限额 → 限额可以定价。

**悬而未决**：“战略史是拒绝的记录”——我是在产出战略管理方法论？
洞察回答“什么是对的”，方法论回答“怎么判断”。现在有的是洞察，
差一步：推广成判断标准（什么样的拒绝可信？限额设在哪里？定价时机？）。
