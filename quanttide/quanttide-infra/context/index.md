# 基础设施

**计费监控**：阿里云的计费问题与费用监控、配置有关，需要通过财务接口持续监控。这是基础设施上需要持续在线的东西。

**PI 作为基础设施程序**：工程上要得到更稳健的结果，理想做法是准备一个容器或服务专门部署 PI，把对 PI 的请求路由到这个微服务，再把它作为基础设施程序使用；各个应用就不需要重复接入 PI。

**可行性看情况**：理论上有办法，实际做起来不一定简单，可能会出现响应慢等各种情况，这对架构的设计与驱动是不小的挑战。

**函数计算与 K8s**：函数计算这个模型不一定适合跑常识任务，放在 K8s 那边可能更合适。

**FaaS 的异步**：用 FaaS 的话，优化要做的事情比较多，首先就得考虑各种异步任务。

**基础设施工作量**：无论用哪个方案，基础设施层都有不小的工作量。

**流程蒸馏**：有很多流程可以去蒸馏，蒸馏出来的作为基础设施云工作的一部分，就能获得海量的工具链。

**从费用出发**：管理基础设施可以类似地从费用出发；成本控制是需要持续做的事情，它就值得做成程序，值得被封装。
