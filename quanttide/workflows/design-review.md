# 设计评审

评审一张界面截图。人先给一句第一眼，智能体再清点、给主诊断与证据、按影响提建议，最后复述一句请人拍板。报告按倒金字塔排。

## 五步

1. impression（人）——第一眼：一句话说这张图给人的整体感受，是判断不是清点，写进报告「第一眼」一节。
2. look——清点：把图上真有的对象、状态、动作、数字逐区写进「看到」一节，只清点、不下判断。
3. review——判断与证据：在「主诊断」写一句话说清最主要的问题，与第一眼对照；「证据」列至多五处、每处点到图上位置；其余观察进「旁枝」；图上读不出、要人确认的进「拿不准」。
4. advise——建议：按影响从大到小排，每条写清改哪里、改成什么、为什么，并标出影响面（安全 / 效率 / 辨识）与改动代价（小 / 中 / 大）。
5. conclude——收口：「结论」开头三行写是什么、问题在哪、先改什么，再一句复述这张图的问题并与第一眼对照，最后列仍拿不准的地方，等人拍板。

## 产物

本任务的报告，排成「第一眼 → 看到 → 主诊断 → 证据 → 旁枝 → 建议 → 结论」。

## 怎么跑

```bash
qtcloud-work task --new <任务名> --workflow design-review
```

再 `qtcloud-work task <任务名> --next`，一条一条走。
